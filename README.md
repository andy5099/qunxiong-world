# 群雄世界 V0.1 — 桃源村與基本戰鬥

PR#1 建立可完整遊玩的第一章起點：建立角色、桃源村、村外平原，以及最多五人的速度制回合戰鬥。

## 已完成

- 輸入角色名稱開始新遊戲，初始隊伍為主角、劉備、關羽、張飛與一個空位。
- 桃源村提供出村、客棧、商店、隊伍與存檔。
- 商店只販售木劍、布衣與回復藥。
- 村外平原可手動或自動探索，遭遇野狼或山賊。
- 戰鬥依速度排序，支援普通攻擊、全隊防禦、主角猛擊與回復藥。
- 自動戰鬥可開關，且使用單一受控計時器。
- 勝利獲得全隊 EXP 與金錢，角色自動升級；戰敗返村並扣少量金錢。
- LocalStorage 保存角色、隊伍、屬性、金錢、所在地與自動戰鬥設定。

## 執行

此專案不需建置。請在 repository 根目錄啟動靜態 HTTP Server，例如：

```powershell
python -m http.server 8877
```

然後開啟 `http://localhost:8877/`。GitHub Pages 亦可直接部署 repository 根目錄。

## 測試

```powershell
node tests/v01-pr1-smoke.mjs
```
