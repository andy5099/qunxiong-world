# 群雄世界 V0.2.1 — Boss 五色角色轉珠戰鬥

V0.2.1 將正式 Boss 戰改為每回合一次的 6×5 手動轉珠。五種顏色固定對應隊伍第 1～5 位，珠面直接顯示角色編號；消除哪一色，該位置的角色才會行動，空隊伍位置不會生成對應色。4 連、5 連、同色多組與 Cascade 都會提高輸出，Combo 倍率則統一套用全隊本回合行動。

拖曳全程使用 Pointer Events、Pointer Capture 與 `requestAnimationFrame` 節流；移動期間只交換並更新兩個既有珠節點，不會重建棋盤、重繪整頁或寫入存檔。6.0 秒倒數在按下珠子時才開始，具備進度條、警告／危險色與背景切換安全結算。普通怪、精英怪與秘境普通層仍沿用快速文字戰鬥和自動探索；所有正式 Boss 與世界王使用轉珠戰。

Boss 轉珠沿用原本的稀有度、Loot、招降、升格、專屬裝備、圖鑑、熟練度及突破資料，不建立第二套獎勵或存檔來源。Boss 戰期間文字戰鬥與自動探索計時器停止，離開戰鬥後會安全恢復原流程。

## V0.2.0 基礎

V0.2.0 新增完整第二章「黃巾之亂」：黃巾荒道、黃巾營地、黃巾主寨、五種敵軍、黃巾校尉／黃巾渠帥／張寶三名可招降 Boss、黃巾古墓四層秘境，以及第二隻三階段世界王「九幽雷獸」。隊伍頁改為五格出戰陣型與候補名冊，可單擊換入並一鍵編成最高戰力，既有武將裝備與存檔完整保留。LocalStorage 版本升級為 14。

赤焰魔虎收服後可使用既有傳說轉職兵符與高階神兵符進行三次 100% 成功突破。突破能力由基礎能力動態計算，保留等級、EXP、熟練度、裝備與出戰位置。

一般裝備加入普通、精良、稀有、史詩四階品質；三件同名同階裝備可升成下一階，並提供單次、全部與全背包一鍵升階。已穿戴數量會從可用素材扣除，Boss 與世界王專屬裝備仍沿用各自系統。LocalStorage 存檔版本升至 13。

本版在既有黑風寨主、秘境與世界王玩法上加入有限且可完成的 Boss 收集目標。圖鑑會記錄五星稀有度的遭遇、擊敗與招降狀態、專屬裝備與兵符；25%／50%／75%／100% 里程碑獎勵只能領取一次。

赤焰魔虎加入 Lv.1～Lv.5 世界王熟練度。只有赤焰魔虎在隊伍中參戰才會累積，熟練度提供生命、武力與技能威力的固定階段加成；世界王頁及圖鑑同時記錄最快擊破回合與單次最高傷害。LocalStorage 存檔版本升至 12，舊存檔會從現有招降紀錄、裝備、兵符與世界王進度補齊圖鑑，不重複發獎。

PR#1 建立可完整遊玩的第一章起點：建立角色、桃源村、村外平原，以及最多五人的速度制回合戰鬥。

## 已完成

- 輸入角色名稱開始新遊戲，初始隊伍為主角、劉備、關羽、張飛與一個空位。
- 桃源村提供出村、客棧、商店、隊伍與存檔。
- 商店只販售木劍、布衣與回復藥。
- 村外平原可手動或自動探索，遭遇野狼或山賊。
- 戰鬥依速度排序，支援普通攻擊、全隊防禦、主角猛擊與回復藥。
- 自動戰鬥可開關，且使用單一受控計時器。
- 勝利獲得全隊 EXP 與金錢，角色自動升級；戰敗返村並扣少量金錢。
- LocalStorage 保存角色、隊伍、屬性、金錢、所在地與自動戰鬥設定。
- 主角 Lv.3 解鎖黑風森林，可手動或自動探索黑風狼、森林山賊與黃巾弓手。
- 森林勝利有機率取得普通、稀有或史詩裝備，掉落會加入共用背包。
- 主角、劉備、關羽與張飛皆可穿戴武器、防具與飾品；裝備比較會逐項顯示能力差異。
- 戰鬥以基礎能力加裝備能力即時計算，支援更換、卸下及出售未裝備物品。
- PR#1 舊存檔會自動遷移至新版裝備欄位與森林解鎖資料。
- 主角 Lv.5 且進入過黑風森林後解鎖黑風寨，可探索寨兵、刀客與頭目。
- 擊破十名寨內敵人後可挑戰黑風寨主與兩名護衛；寨主會使用強襲與威嚇。
- Boss 會掉落獨立的神兵符；可將黑風刀、黑風甲與黑風護符分三階進化至傳說裝備。
- 黑風寨主裝備自己的專屬裝備會觸發武器、防具、飾品與三件套共鳴；其他武將只取得基本屬性。
- 首次勝利可選擇招降或放過；招降成功後寨主加入第五格，成為可升級、戰鬥與穿戴裝備的正常武將。
- 招降後完成第一章，但仍可在既有地區自由探索並重複挑戰寨主。
- LocalStorage version 6 保存寨內擊殺、Boss 狀態、第五名武將、裝備與第一章進度，並相容 version 5 存檔。
- 平原、森林、黑風寨會顯示一至三星危險度、建議戰力與全隊戰力。
- 森林與黑風寨有 10% 機率出現精英敵人；精英具有獨立標示、強化能力與較佳獎勵。
- 黑風寨改為危險探索：前五次不會遇到寨主，第六次起逐次提高機率，第二十次保底出現。
- 寨主出現前會顯示四星警告、隊伍／建議戰力，玩家可安全撤退或迎戰。
- 寨主擁有三件稀有與三件史詩專屬裝備；首次擊敗保證稀有以上，後續可重複打寶。
- 背包提供掉落後快速裝備、一鍵最佳裝備；隊伍頁可從個別裝備欄直接更換。
- LocalStorage version 7 新增精英擊破、寨主遭遇與保底計數，並保留 version 6 的角色、隊伍、裝備與章節資料。
- 黑風寨主每次遭遇會隨機成為普通、精英、稀有、史詩或傳說，能力、技能倍率、建議戰力及獎勵同步提升。
- 所有稀有度可在勝利後嘗試招降；已有寨主時，高階版本會升格原武將而不建立重複隊員。
- Boss 可掉落四階轉職兵符；隊伍頁可消耗對應兵符機率轉職，失敗增加 5% 祝福且不降級。
- 每次擊敗 Boss 必定取得至少一種兵符，高稀有 Boss 的兵符數量與階級更佳；5 張低階兵符可逐級合成 1 張高階兵符。
- Boss 勝利畫面將招降／升格操作置頂；稀有度分布調整為 40%／27%／18%／10%／5%，傳說 Boss 建議戰力 12,000 且可由低戰力隊伍自由硬闖。
- LocalStorage version 8 保存寨主稀有度、兵符、祝福與轉職／招降紀錄，完整相容 version 7。
- 第一章完成後解鎖世界王祭壇，可反覆挑戰固定能力、建議戰力 30,000 的「世界王・赤焰魔虎」。
- 赤焰魔虎具有烈焰撕裂、虎嘯、狂暴橫掃、焚天與獵殺三階段招式，失敗紀錄會保存最佳階段與最低剩餘兵力。
- 世界王勝利提供大量 EXP、金錢、高階兵符、神兵符及赤焰虎爪／赤焰戰甲／赤焰虎符，首勝保證專屬裝備。
- 勝利後可用 5% 機率收服赤焰魔虎；滿隊時安全加入武將名冊，可自行編入或移出五人隊伍。
- 赤焰魔虎穿戴三件世界王專裝會逐件啟動專屬共鳴與「赤焰霸主」套裝效果，其他武將只取得裝備基礎能力。
- LocalStorage version 11 保存世界王挑戰紀錄、收服狀態、武將名冊與專屬裝備，並遷移既有存檔而不重置第一章養成。

## 執行

此專案不需建置。請在 repository 根目錄啟動靜態 HTTP Server，例如：

```powershell
python -m http.server 8877
```

然後開啟 `http://localhost:8877/`。GitHub Pages 亦可直接部署 repository 根目錄。
